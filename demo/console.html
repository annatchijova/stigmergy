Se afirma: la matemática de decisión es exacta e idéntica a la de los módulos Python — refuerzo c' = c + (1−c)·1/5, histéresis EMA β=1/4 con entrada 3/5 / salida 2/5, consenso vigor_for ≥ 1/2 · señales_vivas, todo en racionales BigInt sin ningún float en un veredicto.

The same bytes the cluster would hash. Se afirma: las cadenas de hash son genuinas — JSON canónico con claves ordenadas y sin espacios, decimales como strings de punto fijo a escala 10, hash de entrada sha256(prev_hash ‖ envelope), génesis sha256("STIGMERGY_GENESIS"), hojas Merkle sha256(node_id ":" head).   • Not claimed: this is a CockroachDB deployment, a changefeed, or an AWS Lambda.
